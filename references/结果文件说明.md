# 赛狐广告报表结果文件说明

> **用途**：面向广告分析 Agent 的结果文件速查。做分析前先读本文，即可知道每个文件是什么、怎么来的、字段怎么读。
> **维护规则**：原件存于技能包 `references/`（唯一事实源，修改只改这里）；每次生成结果文件后，复制一份到 `桌面\赛狐广告报表明细\` 一级目录（固定名 `结果文件说明.md`，同名覆盖），供不经过技能包的场景查阅。

## 目录结构

```
桌面\赛狐广告报表明细\
├── 结果文件说明.md            ← 本文档的复制件
├── 赛狐原表数据\              ← API 下载的原始报表（未做任何加工，固定文件名）
├── 赛狐原表筛选结果文件夹\    ← 筛选后的表（6 个：4 种按运行状态筛选 + 搜索词/购买商品按活动ID关联筛选；固定文件名）
└── 广告分析聚合表\            ← 聚合结果 CSV（分析主要用这里的表）
```

## 一、原表（功能简述）

文件名规则：`{报告中文名}.xlsx`（固定名，最新一次拉取覆盖旧文件；本次拉取区间见下载运行日志）。

| 文件 | 功能 |
| --- | --- |
| 广告活动报告 | 天维度 × 活动级 SP 指标（含组合ID、定位类型、运行状态） |
| 广告组报告 | 天维度 × 广告组级指标 |
| 广告产品报告 | 天维度 × 广告产品级指标 |
| 广告位报告 | 天维度 × 活动内广告位级指标 |
| 搜索词报告 | 天维度 × 用户搜索词级指标 |
| 广告购买商品报告 | 天维度 × 购买商品（ASIN/SKU）级指标，含其他ASIN/其他SKU销量/其他SKU销售额 |
| 广告组合信息查询表.csv | 组合基础数据：组合ID → 组合名称映射 |
| 店铺列表.csv | 已授权且启用中的店铺：店铺ID + 店铺名称 |
| 在线产品明细.csv | 店铺在线产品（onlineStatus=active，导出时剔除 sku 含 amzn 的行、按 asin 去重保首次）：shopId + asin + sku，供购买商品聚合做其他ASIN→SKU(sku)映射 |

`赛狐原表筛选结果文件夹\`：下载脚本自动筛选并输出 6 个筛选表——活动/广告组/产品/广告位 4 种按运行状态=已开启筛选（整行过滤，单元格内容不变）；搜索词/购买商品报告无运行状态列，改按 广告活动ID ∈ 筛选后活动报告 关联剔除已暂停活动行（口径与其他维度一致）。聚合脚本默认读这里（固定名优先，缺失回退旧版最新文件）。

## 二、聚合结果文件（广告分析聚合表\）

固定文件名，无日期后缀；同名重新生成即覆盖，同类型永远只有一个文件。

### 通用口径（5 类聚合表共用）

- 编码 UTF-8 BOM（utf-8-sig）
- 数值列均为**字符串文本**：`4.35%` 型已乘100带%号（运算时去%除以100）；ROAS 为倍数 `23.01` 不带%；SUM/AVG 纯数字 2 位
- ACoS = Σ花费/Σ销售额（非平均）；ROAS = Σ销售额/Σ花费；CPC/点击率/转化率为组内简单平均
- 零删行：各组行数总和 = 输入行数（脚本内置校验，不过则退出 1）
- 空单元格跳过该格累加；组合ID/组合名称为空 = 活动关联不到组合（多为已暂停活动；搜索词/购买商品经活动ID关联筛选后一般不再出现），非数据错误

**通用指标列**（下述各表均含，口径一致）：

| 列 | 口径 |
| --- | --- |
| 广告花费 / 广告曝光量 / 广告点击量 | SUM |
| CPC | AVG |
| 广告点击率 / 广告转化率 | AVG，`x.xx%` 格式 |
| ACoS / ROAS | 比值推导（见上） |
| 广告销售额 / 本广告产品销售额 / 其他产品广告销售额 | SUM |
| 广告订单量 / 本广告产品订单量 / 其他产品广告订单量 | SUM |
| 广告销量 / 本广告产品销量 / 其他产品广告销量 | SUM |

每个 `_周维度` 变体：分组键追加"日期所在周"（**以输入数据最晚日期为终点，倒数连续 7 天为一周**，开头剩余天数不足 7 天时仍计为一周，保证最近一周永远满 7 天，不按自然周/周一切分），增加日期列显示该组实际最早~最晚日期（非整周边界），指标口径与全量表完全一致；另增「月份」「实际天数」两列标记周归属——月份 = 该周起始日（锚点 − 7×周序 − 6 天，即桶内最早一天）的年月（中文格式 `2026年8月`，避免纯 `2026-08` 被 Excel 打开时误转成 `Jul-26` 类日期显示），实际天数 = 该周内实际有数据的天数（组内不同日期数：完整周为 7，最旧一桶为实际剩余天数，周内缺天时如实显示），空周组（日期为空）两列留空。

### 1. 广告组合聚合.csv（+ _周维度）

- **来源**：广告活动报告.xlsx（筛选结果文件夹，固定名优先，缺失回退历史最新）
- **生成逻辑**：按 [广告组合ID] 分组聚合通用指标列；组合名称经 广告组合信息查询表.csv 关联插入
- **字段**：广告组合ID（分组键）、广告组合名称（关联列）+ 通用指标列

### 2. 广告活动聚合.csv（+ _周维度）

- **来源**：同上
- **生成逻辑**：按 [广告组合ID + 广告活动ID + 定位类型] 分组；广告活动（名称）组内保留唯一值；组合名称关联补齐
- **字段**：广告组合ID、广告活动ID、广告活动、定位类型、广告组合名称 + 通用指标列

### 3. 广告位聚合.csv（+ _周维度）

- **来源**：广告位报告.xlsx + 广告活动报告.xlsx（筛选结果文件夹，固定名优先）；组合ID/名称经 广告活动报告 按活动ID关联
- **生成逻辑**：按 [广告活动ID + 广告位 + 定位类型] 分组（广告位报告无组合列）
- **字段**：广告活动ID、广告位、定位类型、广告活动、广告组合ID、广告组合名称 + 通用指标列

### 4. 搜索词聚合.csv（+ _周维度）

- **来源**：搜索词报告.xlsx（筛选结果文件夹，活动ID关联筛选版，固定名优先）；组合ID经 广告活动报告 按活动ID关联
- **生成逻辑**：按 [用户搜索词 + 匹配类型 + 投放 + 广告活动ID + 定位类型] 分组；组合名称取报告原生列（多值以 `A|B` 合并）
- **字段**：上述 5 个分组键 + 广告活动、广告组合ID、广告组合名称 + 通用指标列

### 5. 购买商品聚合.csv

- **来源**：广告购买商品报告.xlsx（筛选结果文件夹，活动ID关联筛选版，固定名优先）+ 广告活动聚合.csv（排除周维度变体）做组合ID/名称关联 + 在线产品明细.csv 做 ASIN→SKU(sku) 映射
- **生成逻辑**：按 [广告活动ID + ASIN + SKU + 投放 + 定位类型] 分组；其他ASIN 组内去重（含格内逗号拆分）后输出为 **ASIN→SKU 映射字典**（紧凑 JSON，键序=组内首次出现顺序；SKU 查在线产品明细的 sku 列（接口 rows.sku），一个ASIN对应多个SKU时值内以 `;` 拼接全部去重，明细未收录的ASIN值为空串）；其他SKU销量 SUM；其他SKU销售额 SUM；两列均做总额对账（Σ各组 == 原表逐行合计，不等退出 1）
- **字段**：5 个分组键 + 广告活动（唯一值）、其他ASIN（ASIN→SKU 字典）、其他SKU销量（SUM）、其他SKU销售额（SUM）、广告组合ID、广告组合名称（关联列）

## 依赖提醒（分析前自查）

购买商品聚合依赖两张前置表——**广告活动聚合.csv**（组合ID/名称关联）与**在线产品明细.csv**（其他ASIN→SKU 翻译）。在线产品明细由 `fetch_sellfox_online_products.py --shop-ids <与报表同批的店铺ID>` 导出，只含 active 在线产品（下架ASIN在字典中留空），产品变动时需重跑导出。若下载后只重跑了部分聚合，先确认 广告活动聚合.csv 与购买商品报告同期，否则组合关联会失真。
